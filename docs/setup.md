# Setup

## Environment

This project is designed primarily for Databricks Free Edition.

The implementation avoids mandatory dependencies on:

- Azure infrastructure
- GPU clusters
- Azure OpenAI
- external vector databases
- paid cloud services

## Development

1. Create a Databricks Free Edition workspace.
2. Connect GitHub.
3. Clone this repository as a Databricks Git folder.
4. Use serverless notebook compute.
5. Run the environment verification notebook.
6. Continue through the project phases.

Detailed setup instructions will be expanded as the project is implemented.
